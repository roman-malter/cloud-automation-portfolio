## 📁 Featured Projects

### 🌐 High-Availability Networking & Infrastructure
#### [Project 5: Cisco HSRP Enterprise Gateway Redundancy Simulation](./cisco_topology.png)
Designed and validated a resilient, fault-tolerant corporate perimeter network utilizing **HSRP (Hot Standby Router Protocol)** within Cisco Packet Tracer.
* **First-Hop Redundancy:** Configured virtual default gateways across multiple boundary routers (R1 and R2) to ensure uninterrupted connectivity to external servers (`www.cisco.pka`) during an active gateway failure.
* **Full-Mesh Switching Matrix:** Deployed a highly redundant, loop-free interconnected switch infrastructure across corporate endpoint terminals.
* **Troubleshooting & Remediation:** Diagnosed and corrected misconfigured standby group priorities and gateway path designations to stabilize traffic failovers.
* *The Cloud Pivot:* This physical framework directly mirrors high-availability concepts used to design load-balanced, multi-zone architectures within **Azure Virtual Networks (VNets)**.
